# Переклад інтерфейсу — заповнення вручну

Тут лежать JSON-шаблони для мов, які ще НЕ перекладені (показували англійську):
`ar, bn, cs, el, fa, he, hu, ja, ko, ms, ro, sv`.

У кожному файлі 262 ключі. Значення зараз — англійський текст (орієнтир).
Твоє завдання: **замінити праву частину на переклад**. Ключі (ліворуч) не чіпай.

```json
{
  "nav_explore": "Explore",   ← заміни "Explore" на переклад
  "nav_fields": "Fields",
  ...
}
```

## Коли заповнив — збери в робочі бандли

```bash
cd neuron_frontend
npm run i18n:compile            # збере всі мови з цієї папки
npm run i18n:compile -- ja ko   # або тільки вибрані
```

Скрипт створить/перезапише `lib/locales/<code>.js`, які реально завантажує застосунок,
і покаже, скільки ключів ще лишилось англійською.

## Поради

- Зберігай переклад тих самих плейсхолдерів, що в англійській: `{count}`, `{name}` тощо — не перекладай те, що у фігурних дужках.
- Лапки всередині тексту екрануй як `\"` (це звичайний JSON).
- Порожнє значення `""` → скрипт лишить англійський текст для цього ключа (не зламається).
- Після `i18n:compile` зроби `npm run build`, щоб перевірити, що все збирається.

> Альтернатива (автопереклад через API, потрібен інтернет):
> `npm run i18n:build -- ja ko ar ...` — але якість гірша, краще вичитати вручну.
