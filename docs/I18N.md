# UI localization

Neuron has two language layers:

| Layer | What changes | Storage |
|-------|----------------|---------|
| **Interface** | Menus, buttons, labels (`t('key')`) | `localStorage` `neuron_locale` |
| **Content** | Posts and comments (auto-translate) | `neuron_content_locale` + profile |

Both use the same list of languages as in the header picker (28 codes + Original for content only).

## Files

- `neuron_frontend/lib/locales/en.js` — source strings (262 keys)
- `neuron_frontend/lib/locales/{code}.js` — per-language UI bundles
- `neuron_frontend/lib/i18n.js` + `I18nContext.js` — runtime
- `neuron_frontend/scripts/build-ui-locales.mjs` — generate bundles via MyMemory

## Generate / update translations

```bash
cd neuron_frontend
npm run i18n:build -- uk ru          # one language
npm run i18n:build -- de fr es       # several
node scripts/build-ui-locales.mjs --all   # all (~30 min, rate limits apply)
```

After adding keys to `en.js`, rebuild affected locales.

## Adding a new UI string

1. Add key to `lib/locales/en.js`
2. Use `t('your_key')` in components
3. Rebuild locale files or add manual entry in each `lib/locales/{code}.js`

## RTL

Arabic, Hebrew, and Persian set `dir="rtl"` on `<html>` when selected.
